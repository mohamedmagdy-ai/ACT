# تحديث v1.3.21 — رفع صور المنتجات مجانًا (GitHub بدل Firebase Storage)

## سؤالك

"عاوز احل موضوع الصور بتاعة الاصناف المعروضة بس يكون حل مجانى"

## المشكلة

زرار "🖼️ صورة المنتج" في شاشة تعديل الصنف كان بيحاول يرفع الصورة على
Firebase Storage — لكن Firebase غيّرت سياستها من شهور: أي استخدام لـ
Storage (حتى الأساسي) بقى محتاج تفعيل خطة الدفع بالاستخدام (Blaze) وربط
بطاقة بنكية بالمشروع، حتى لو الاستخدام الفعلي هيفضل صفر جنيه تمامًا. من
غير كده، الرفع كان بيفشل بصمت أو برسالة خطأ مش واضحة.

## الحل

بديل مجاني بالكامل ومن غير أي بطاقة بنكية: رفع الصورة على مستودع GitHub
خاص بيك (مجاني بالكامل)، وعرضها للعملاء عن طريق jsdelivr (شبكة توصيل محتوى
مجانية بتقرأ مباشرة من GitHub، سريعة وموثوقة).

### إعداد لمرة واحدة (من "الإعدادات" ← "🛒 المتجر الأونلاين")

قسم جديد "🖼️ استضافة صور المنتجات (مجانًا عن طريق GitHub)":

١. اعمل حساب مجاني على github.com (لو مفيش عندك)، وأنشئ مستودع
   (repository) جديد فاضي وعام (Public) — مثلاً باسم `act-product-images`.
2. من github.com/settings/tokens اعمل Personal Access Token (Fine-grained)
   بصلاحية "Contents: Read and write" على المستودع ده بس.
3. حط اسم المستخدم، اسم المستودع، والـ Token في الحقول الجديدة واضغط
   "حفظ". البيانات دي بتتخزن على جهازك بس، ومش بتتبعت لموقع المتجر أو
   لأي حد تاني.

بعد الإعداد ده، زرار "رفع صورة" في شاشة تعديل أي صنف هيرفعها تلقائي (وهيصغّرها
على جهازك الأول عشان الرفع يبقى أسرع وحجمها أصغر)، ويحط رابطها جاهز.

لو مش عاوز تعمل الإعداد ده دلوقتي، طريقة "الصق رابط صورة" (اللي كانت موجودة
أصلاً) لسه شغالة زي ما هي بالظبط.
