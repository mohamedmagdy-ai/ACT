# تحديث v1.3.30 — ميزة جديدة: عدّاد زوار الموقع (يظهر ليك إنت بس)

## الطلب

"جاتلى فكرة ان الموقع بتعنا يبقى فى عداد لعدد زوار الموقع حتى ليا انا بس اشوفة" — وبعد ما سألتك فين بالظبط عايز تشوفه، اخترت الاتنين: لوحة متابعة المحل على الموبايل، وبرنامج سطح المكتب.

## اللي اتعمل

ضفنا عدّاد "👁 زوار الموقع" بيورّي إجمالي عدد الزيارات الحقيقية للموقع من أول ما اتفعّل — ظاهر **ليك إنت بس**، مش لأي زائر للموقع:

- **في برنامج سطح المكتب**: كارت جديد في لوحة التحكم الرئيسية (نفس شكل باقي الكروت)، ظاهر للمدير بس زي باقي الكروت الحساسة.
- **في لوحة متابعة المحل على الموبايل**: رقم جديد في أول كارت (كارت "مبيعات النهارده")، وبيتحدّث لايڤ زي باقي الأرقام.

### إزاي بيشتغل من غير ما يأثر على أمان الموقع

الموقع (اللي أي زائر بيدخله من غير تسجيل دخول) بيسجّل "زيارة" واحدة بس لكل جلسة متصفح (يعني لو حد فتح صفحتين أو عمل رفرش، مش بيتحسبله مرتين) — بنفس الطريقة الآمنة اللي بيتسجل بيها طلب أونلاين أو رسالة "تواصل معنا" بالظبط: مستند صغير فاضي تقريبًا بيتسجل، والبرنامج (وهو بس، لأنه مسجل دخول بحساب المدير) هو اللي بيقرا الزيارات الجديدة كل ٣٠ ثانية، يعدّها، يمسحها، ويزوّد الرقم الإجمالي. مفيش أي بيانات شخصية عن الزائر بتتسجل خالص — رقم بس.

**ملحوظة مهمة**: العداد دلوقتي بيسجل زيارات الصفحة الرئيسية للموقع بس (أكتر صفحة أي زائر جديد بيدخلها، خصوصًا جايين من فيسبوك). لو حبيت بعدين نضيف صفحات تانية (صفحة المنتج، صفحة "مين إحنا"...) قولّي وهنزوّدها.

## الملفات اللي اتغيّرت

- `app/index.html` — منطق القراءة والعدّ في البرنامج + الكارت الجديد في لوحة التحكم
- `storefront/public/app.js` — تسجيل الزيارة من جهة الموقع
- `mobile-dashboard/index.html` و `mobile-android/www/index.html` — عرض الرقم في لوحة المتابعة
- `package.json` (النسخة 1.3.30)

اختبار جديد مخصص (١١ حالة) اتعمل يتأكد من الآلية كاملة (تسجيل الزيارات، عدّها، مسحها، زيادة الرقم الإجمالي صح من غير استبدال، وصول الرقم للوحة تحكم البرنامج ولملخص الموبايل) — بالإضافة لكل ملفات الاختبار القديمة (٣٢ ملف) اللي عدّت بنجاح من غير أي تراجع.

## خطوات التطبيق

### ١) برنامج سطح المكتب
استبدل `app/index.html` و`package.json` في نسخة مشروعك، واعمل نسخة تثبيت جديدة ونشرها بنفس طريقتك المعتادة:
```
npm run dist
```

### ٢) لوحة متابعة الموبايل
استبدل `mobile-dashboard/index.html` و`mobile-android/www/index.html`، وابعتهم بنفس خطوات الرفع اللي اتفقنا عليها قبل كده (`git add` / `git commit` / `git push` لمشروع الموبايل، وبعدها GitHub Actions هتبني الـAPK لوحدها).

### ٣) الموقع (استضافة Firebase) — خطوة إضافية مهمة
الموقع نفسه (`storefront/public/app.js`) مش جزء من نسخة التثبيت ولا مشروع الموبايل — لازم يترفع لاستضافة Firebase بشكل منفصل عشان تسجيل الزيارات يبدأ فعليًا. من داخل مجلد `storefront`:
```
firebase deploy --only hosting
```
لو مش فاكر الأمر ده أو حصلت مشكلة وانت بتنفذه، قولّي وهمشي معاك خطوة خطوة.
