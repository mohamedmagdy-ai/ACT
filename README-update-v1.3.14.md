# تحديث v1.3.14 — إصلاح: فواتير الآجل كانت بتوري "اللي ليا" بس من غير "اللي عليا"

## سؤالك

"فواتير الآجل غلط جايبلى اللى ليا بس مش اللى عليا هل دا صح؟"

## الإجابة

كنت لاحظ صح — الكارت القديم "🧾 فواتير آجلة مستحقة" كان بيوري بس إجمالي
واحد لـ"مستحق ليا" (فلوس العملاء عندك)، وأصلاً حتى مكانش فيه قايمة تفصيلية،
كان رقم واحد بس. "مستحق عليا" (فلوس موردين عندهم منك) كان موجود بس مدفون
جوه كارت "📊 التقرير الشامل" كرقم واحد كمان، مش قايمة تقدر تشوف تفاصيلها.

## اللي اتعمل

الكارت القديم اتقسم لكارتين منفصلين، كل واحد فيه **قايمة تفصيلية** (مش رقم
إجمالي بس):

- **🟢 مستحق ليا (فواتير عملاء آجلة):** كل فاتورة بيع/صيانة آجلة لسه ماتحصّلتش،
  مرتبة من الأكبر للأصغر، وكل سطر فيه اسم العميل ورقم الفاتورة والمبلغ.
- **🔴 مستحق عليا (فواتير موردين آجلة):** كل فاتورة مشتريات آجلة لسه ما
  اتسددتش، بنفس الترتيب — اسم المورد ورقم الفاتورة والمبلغ.

بيوريلك آخر ١٥ فاتورة في كل قايمة (الأكبر مبلغًا الأول).
