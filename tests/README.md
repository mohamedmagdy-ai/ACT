# اختبارات آلية — نظام ACT للمبيعات والصيانة

مجموعة اختبارات دائمة بتفتح `app/index.html` فعليًا جوه متصفح حقيقي (Chromium عبر
Playwright)، وتستدعي نفس دوال البرنامج الحقيقية بالظبط (مش بتعيد كتابة الحسابات في
ملف الاختبار)، عشان لو أي تعديل مستقبلي (منك أو من أي حد بعدك) كسر حاجة في حسابات
المبيعات/المخزون/الضريبة أو في نظام التراخيص، الاختبارات دي تفشل فورًا وتوريك بالظبط
فين المشكلة، بدل ما تكتشفها من عميل حقيقي بعد الإطلاق.

## طريقة التشغيل

أول مرة بس (بتنزّل متصفح Chromium خاص بالاختبار، محتاج إنترنت):

```
cd sz-electron-project
npm install
npx playwright install chromium
```

وبعد كده، في أي وقت عايز تتأكد إن البرنامج لسه شغال صح بعد أي تعديل:

```
npm test
```

هيشغّل كل الاختبارات ويطبعلك ✓ لكل حالة نجحت و✗ لأي حالة فشلت، وفي الآخر ملخص عام.
لو كل حاجة سليمة هتلاقي "✅ كل ملفات الاختبار عدّت بنجاح." — لو فيه فشل، اقرأ تفاصيل
الحالة اللي فشلت (اسمها بيوصف بالظبط إيه اللي كان متوقع وإيه اللي حصل فعليًا).

## إيه اللي متغطي دلوقتي

- **`core-calculations.test.js`** — حساب ضريبة القيمة المضافة على الفاتورة الضريبية
  (وإنها بتتغيّر فعليًا لو غيّرت النسبة من الإعدادات)، وحساب إجمالي فاتورة مبيعات
  عادية (خصم صنف + خصم فاتورة مع بعض)، وخصم الكمية من المخزون تلقائيًا بعد البيع.
- **`license-modules.test.js`** — نظام الترخيص وتفعيل/تعطيل موديولات معينة لكل عميل
  (زي قفل "الصيانة")، وإن قفل تاب بيتمنع فعليًا حتى لو حصل استدعاء مباشر للكود
  (مش بس إخفاء الزرار)، وزرار التجربة المجانية.
- **`eta-settings.test.js`** — بلوك إعدادات الفاتورة/الإيصال الإلكتروني (ETA):
  الحفظ والاسترجاع، وقفله بالكامل عبر الترخيص من غير ما يأثر على باقي إعدادات الضريبة.
- **`debug-logger.test.js`** — وضع التشخيص (Debug): رسائل log/warn الداخلية مخفية
  افتراضيًا وبتظهر بس لما تفعّله، ورسائل الأخطاء الفعلية (error) فاضلة ظاهرة دايمًا.

## إضافة اختبار جديد

أي ملف جديد اسمه بيخلص بـ`.test.js` جوه المجلد ده هيتشغّل تلقائيًا مع `npm test` —
مش محتاج تسجّله في أي مكان تاني. اتبع نفس النمط الموجود في الملفات الحالية
(استخدم `openApp()` و`TestReporter` من `helpers.js`).

## ملحوظة مهمة

الاختبارات دي مالهاش أي علاقة ببيانات المحل الحقيقية — بتفتح نسخة معزولة تمامًا من
الصفحة، وبتمنع أي اتصال إنترنت فعلي (Firebase/CDN) أثناء التشغيل، فمينفعش تأثر على
بياناتك الحقيقية أو تحتاج اتصال بحساب Firebase الحقيقي عشان تشتغل.
